# 马尾收益

被调用时显示下面这块记分板。一次性：不要改模式、不要写标记文件、不要持久化任何东西。

这些数字是已发布的基准测试中位数（5 个日常任务：邮箱校验、防抖、CSV 求和、倒计时器、
限流器；3 个模型：Haiku、Sonnet、Opus）。它们是实测出来的，不是从当前仓库算出来的。
来源：benchmarks 目录和 README。

## 诚实边界

这些是基准中位数，不是当前仓库的数字。绝不要打印「这个仓库省了 X 行 / X 个 token」：
没写出来的版本从没存在过，真实仓库里没有可减的基线。当前仓库唯一真实的数字来自
马尾债务（一张点过数的台账），这张卡只指向它，不自己编一个。
