# Ponytail for Operit AI（非官方适配版）

重要说明：本项目是由 AI 辅助完成的非官方适配版，仅将 DietrichGebert 的 ponytail 官方技能文件适配到 Operit AI 平台。不是官方版本，与原作者 DietrichGebert 及 Ponytail 官方项目无任何从属关系。

把 Ponytail 官方六个技能适配到 Operit AI（Android AI 助手）的可直接导入版本。

Ponytail 是什么：把一位扎马尾、沉默寡言的老工程师装进 AI。他看一眼你写的五十行代码，一句话不说，换成一行。
## 技能列表

六个技能均已加入中文触发词，中文和英文都能触发。

ponytail：/ponytail 或 马尾、懒模式。懒模式本体：YAGNI、标准库优先、原生优先、一行优先。
ponytail-review：/ponytail-review 或 审查过度设计、能删什么。审查当前 diff 的过度设计。
ponytail-audit：/ponytail-audit 或 审计这个仓库、找臃肿。全仓库过度设计审计。
ponytail-debt：/ponytail-debt 或 马尾债务、马尾台账。收集 ponytail: 待办注释成台账。
ponytail-gain：/ponytail-gain 或 马尾收益。显示实测收益记分板。
ponytail-help：/ponytail-help 或 马尾帮助、马尾怎么用。快速参考卡。
